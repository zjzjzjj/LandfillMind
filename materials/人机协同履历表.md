## 四、本作品 AI 协同工作流

### 4.1 任务拆分（评审重点）

将"填埋场全周期智能体"拆分为 **4 个平行智能体 + 1 个综合智能体**：
- 边坡稳定分析（GB 50330-2013 / CJJ 176-2012）
- 渗滤液产量与导排（CJJ 176-2012 §5.1 / GB 16889-2008 §5）
- 填埋气产气与甲烷迁移（USEPA LandGEM / GB 16889-2008 §6）
- 地下水污染调查与阻隔（HJ 25.6 / GB/T 14848 / GB 36600-2018）
- 综合 Agent 携带同伴结论做最终研判

### 4.2 AI 编排策略

**提示词四段拼装**：
```
MA_SYSTEM_PROMPTS[role]   // 角色约束（如"边坡稳定专家"）
+ MA_COMMON_RULES          // 通用规约（5 节输出格式）
+ KEY_THRESHOLDS_JSON      // 阈值速查表（Fs/CH₄/液位等）
+ pickScenarioAdvice()     // 场景路由
```

**性能优化**：服务启动时 **LRU 预热缓存** 4 个领域 Agent 的演示场景，首跑命中即秒回。

### 4.3 关键数值由内核判定

5 类关键数值（**Fs / 渗滤液年产量 / CH4 浓度 / 地下水浓度 / 边坡稳定**）由**确定性工程计算内核**（`server/calculate.ts`）直接计算，LLM 仅生成解释散文，避免越权捏造。

### 4.4 追问链路（真实专家换脑）

`MultiAgentPage` 5 专家并行渲染后，任意专家卡片"**追问这位专家**"按钮：
1. 通过 `sessionStorage.chat-prefill-expert.agentId` 写入真实专家身份
2. `ChatPage` 挂载时从 `expertPrompts.ts:EXPERT_SYSTEM_PROMPTS` 映射到对应 `MA_SYSTEM_PROMPTS[slope/leachate/lfg/gw/summary]`
3. **真正把该专家的 systemPrompt 发给 LLM**（换脑而非 UI 假象）
4. 顶部 Banner 配合霓虹角标显示"已切换为：边坡稳定专家"

### 4.5 AI 纠偏管理（双引擎核心）

**架构**：引擎 A 确定性工程计算内核（12 项计算器 / 198 条规范 / 4 类风险等级判定）+ 引擎 B LLM 解释层（智谱 GLM-4-Flash）+ 引擎 C 交叉复核纠偏层

**可视化**：将静态 mismatch 卡片升级为 **分屏剧场化 UI**（`src/components/VerificationTheater.tsx`）：
- 左侧黑玻璃感卡片承载 AI 报告原文
- 中部动画竖线逐条穿过 mismatches
- 右侧黄色玻璃感卡片展示计算内核真实结论
- 底部时间线步进支持上一步/下一步/全部展开
- 演示数据 `DEMO_RESULT_CORRECTED` 预填 **3 处结构化 mismatch**（slope Fs 漏报 / leachate 数值缺失 / lfg CH₄ 等级误判）
- 评审现场可一键复现 AI 纠偏全过程

### 4.6 自进化闭环（业界首创）

```
用户反馈（👎 + 评论）
    ↓
[LLM DeepSeek 蒸馏]  →  KB 草案（key/q/pro/easy/cite/kw）
    ↓
工程师人工 review
    ↓
合并到 server/kb.ts → 立即生效
```

**当前状态**：
- 已部署 198 条 KB 条目
- 蒸馏队列机制已上线（`/api/feedback/distill`）
- 待真实用户反馈积累后开始 review

## 五、复盘心得

### 5.1 AI 在工程级场景的优势

- **跨学科综合能力**：1 个 AI 助手同时理解边坡/渗滤液/气体/地下水/法规，比单个工程师专精 1 个领域更全面
- **响应速度**：3 秒出具跨学科报告，1000× 提速
- **不疲劳**：7×24 在线，班组安全员班前 5 分钟即可获得"今天能不能进场"的判断
- **可审计**：每条结论都引用国标条款号 + 计算公式 + 数值，反向可验证

### 5.2 AI 在工程级场景的边界

- **会编造条款号**：必须用"确定性内核 + 交叉复核"约束
- **会漏报**：必须用剧场化 UI 强制呈现
- **不能替代工程师判断**：最终决策权永远在工程师手中（双引擎设计 + AI 报告标"参考"而非"结论"）

### 5.3 L4–L6 能力的工程化路径

- **L4 流程自动化**：从 0 到 MVP 的 6 步流水线（需求 → 架构 → 代码 → 测试 → 部署 → 文档）每个环节都让 AI 重复参与
- **L5 智能体**：从单 LLM 调用 → 角色分工 → 多智能体 → 真实换脑 → 反馈闭环
- **L6 业务创新**：不是替代工程师，而是让工程师"不再需要算 Fs / 翻规范"，专注于"判断 + 决策 + 沟通"
